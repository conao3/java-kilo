# java-kilo

A Java implementation of the kilo text editor, following the [Build Your Own Text Editor](https://viewsourcecode.org/snaptoken/kilo/) tutorial.

## Overview

Kilo is a minimal terminal-based text editor written in fewer than 1,000 lines of code. This project reimplements the original C tutorial in Java, providing a hands-on way to learn about terminal I/O, raw mode input handling, and text editor internals.

## Requirements

- Java 11 or later
- A Unix-like terminal (Linux, macOS, or WSL on Windows)

## Build and Run

```bash
javac Kilo.java
java Kilo
```

## Controls

- Arrow keys: Move cursor
- Ctrl+Q: Quit

## Current Status

Following the tutorial at the "Arrow keys" section (Chapter 3: Raw Input and Output).
